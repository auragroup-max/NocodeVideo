# Notes du projet · Le dropshipping expliqué

## Faits à vérifier (pas dans la vidéo)

- Le vendeur paie le fournisseur après la commande du client : vrai dans le schéma classique (AliExpress, CJ, etc.), mais certaines plateformes ou fournisseurs demandent un dépôt ou un abonnement.
- « Le colis ne passe jamais par chez toi » : vrai pour l'envoi direct fournisseur → client. Les retours peuvent compliquer les choses.
- Recevoir les paiements depuis Madagascar (Shopify Payments / Stripe indisponibles) : sujet d'une vidéo à part, volontairement absent ici.
