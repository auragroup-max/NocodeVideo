// le principe en une phrase

Tu décris la vidéo.

L’IA écrit le code.

L’ordinateur la filme, image par image.

Toi : tes mots

Claude Code : le code

Le rendu : ta vidéo MP4

Retiens juste ça. Une vidéo, c’est une page web qui bouge. Claude Code écrit cette page à partir de ta demande, puis l’ordinateur la prend en photo 60 fois par seconde : ça donne une vidéo.
