Deux options : HyperFrames et Remotion

HTML + GSAP

HyperFrames

La vidéo écrite comme une page web animée. La méthode la plus proche de la mienne.

Idéal pour : vidéos explicatives, sous-titres animés, diaporamas, pubs courtes.

REACT

Remotion

La vidéo écrite en React, le langage de beaucoup de sites modernes. Très utilisé pour les vidéos de produits.

Licence : gratuite pour un particulier ou une petite équipe, payante pour les plus grandes entreprises.

Pour l’utiliser, demande simplement : « Fais cette vidéo avec HyperFrames » ou « avec Remotion ». Claude installe ce qu’il faut.

Pas obligatoire pour commencer : ma méthode suffit. Mais si vous voulez aller plus loin, ces deux outils sont faits pour créer des vidéos en code, et Claude sait les utiliser. Pour Remotion, vérifiez les conditions de licence sur remotion.dev si vous travaillez pour une entreprise.
