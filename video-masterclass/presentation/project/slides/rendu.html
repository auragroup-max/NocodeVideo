Le rendu : la page devient une vidéo

Chrome ouvre la page et la prend en photo, image par image. Ensuite, les images sont assemblées avec la voix et les petits sons.

60

images par seconde, pour une vidéo fluide

1080×1920

le format vertical de TikTok, Reels et Shorts

−14

LUFS : le bon volume pour les réseaux

Le réflexe pro : avant le rendu complet, demande une planche d’images fixes pour repérer les défauts.

Le rendu prend quelques minutes. Pour ne pas les perdre, on vérifie d’abord une planche d’images à des moments clés : un texte qui dépasse, un élément mal placé. On corrige, puis on lance le vrai rendu.
