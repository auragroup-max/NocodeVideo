Le texte à publier

TikTok

La légende : deux phrases, puis où t’écrire.

Une question pour lancer les commentaires.

3 à 5 hashtags, pas plus.

YouTube Shorts

Le titre : clair, avec le mot que les gens cherchent.

La description : les étapes, puis où t’écrire.

Les tags : même les fautes de frappe courantes.

Règle d’or : jamais de promesse de gain. Écris « peut », « si », « souvent ».

Claude Code peut aussi t’écrire ces textes : demande-lui la légende, la question et les hashtags une fois la vidéo validée. Relis toujours avant de publier : c’est toi qui postes, jamais l’IA.
