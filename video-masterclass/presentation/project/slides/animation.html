L’animation par Claude Code

Toi, tu donnes

  • Le MP3 de la voix.
  • Le script, mot pour mot.
  • Le style que tu veux.
  • Ton idée pour chaque passage.

Claude Code fait

  • Il note le moment exact de chaque mot.
  • Il écrit la page qui s’anime.
  • Il fait apparaître chaque élément sur son mot.
  • Il fait parler le présentateur.
Toi, tu restes le réalisateur : tu dis ce que tu veux voir. Claude Code fait le travail technique : il écoute la voix, il repère chaque mot, et il cale l’animation dessus.
